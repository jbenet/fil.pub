# Contributing

This repository is published from fil.pub's main (private) repository: every commit here is a
snapshot made by CI, and anything committed here directly is overwritten by the next one.

Pull requests are welcome all the same. A maintainer applies your change upstream, with you
credited, and it comes back here with the next snapshot. Bugs and ideas go to the feedback
button on [fil.pub](https://fil.pub) (Alt+F).

`fp` has no dependencies and no build step: it runs on Node 22.13 or later with nothing but
`node:` built-ins, and should stay that way.
